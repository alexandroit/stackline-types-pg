# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

Report suspected vulnerabilities through GitHub private vulnerability
reporting for `alexandroit/stackline-types-pg`, not a public issue.

A release is blocked when any direct, transitive, optional, peer-installed, or
bundled production node is deprecated, abandoned, vulnerable, invalid, or
unreviewed. Remediation proceeds from the deepest failing leaf.
