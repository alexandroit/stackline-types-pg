# Compatibility

The declaration files in `@stackline/types-pg@1.0.0` are byte-identical to
`@types/pg@8.23.1`, whose DefinitelyTyped content hash is
`4c3006364fd06c962ce8e915a3dcf8d0d87bfec39f509aa95b270ad620cad104`.

Install through the `@types/pg` npm alias to preserve automatic TypeScript
module resolution, imports from `pg`, CJS and ESM declarations, and deep
`pg/lib/*` declaration paths. The package retains the upstream TypeScript 5.6
minimum.
