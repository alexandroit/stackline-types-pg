# Project Memory

- Package: `@stackline/types-pg`
- Baseline: `@types/pg@8.23.1`
- Required compatibility install: `@types/pg@npm:@stackline/types-pg`
- Runtime companion: `pg@npm:@stackline/pg`
- Type declarations are immutable upstream bytes; only metadata, dependencies,
  tests, and documentation may differ.
- Production dependency review is recursive and leaf first.
- Every release requires warning-free direct and alias installs, valid complete
  trees, zero audits, TypeScript compilation, SBOM, checksums, attribution,
  immutable GitHub release, public docs, catalog, and Drive evidence.
